# Demo assets

| File | Purpose |
|---|---|
| `agensh-demo-1024-3200x2400.mp4` | Original 75-second H.264 video at 3200 × 2400 |

The GIF is generated from the MP4 and plays inline using standard Markdown.
Click it in the [root README](../README.md#demo) to open the
