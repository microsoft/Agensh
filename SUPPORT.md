# Support

## How to file issues and get help

Use [GitHub Issues](https://github.com/microsoft/magens/issues) to report bugs,
request features, and ask questions about configuring or running this project.
Search existing issues before opening a new one. Include the commit, launch
path, steps to reproduce, and relevant logs with credentials removed.

Report security vulnerabilities using the instructions in [SECURITY.md](SECURITY.md).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
